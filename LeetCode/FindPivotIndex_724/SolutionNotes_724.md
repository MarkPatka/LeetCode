Чтобы проверить условие для каждого индекса за O(1), заранее вычисляем массив **префиксных сумм**:

- `prefixSum[i]` = сумма первых `i` элементов исходного массива (т.е. элементов с индексами `[0 .. i-1]`).
- Длина `prefixSum` = `n + 1`, где `prefixSum[0] = 0`.

Тогда для индекса `p` в исходном массиве:

- **Левая сумма** (элементы строго слева) = `prefixSum[p]`
- **Правая сумма** (элементы строго справа) = `totalSum - prefixSum[p+1]`  
  (где `totalSum` = `prefixSum[n]`).

## Алгоритм

1. Построить `prefixSum` длиной `n+1`, где `prefixSum[i]` = сумма `nums[0] + ... + nums[i-1]`.
2. `total = prefixSum[^1]` (последний элемент, т.е. сумма всех чисел).
3. Для каждого `i` от 1 до `prefixSum.Length-1` (это соответствует индексу `p = i-1`):
   - Левая сумма = `prefixSum[i-1]`
   - Правая сумма = `total - prefixSum[i]`  
     (так как `prefixSum[i]` включает текущий элемент и все слева от него).
   - Если левая == правая, возвращаем `p = i-1`.
4. Если ни одно условие не выполнено, возвращаем `-1`.
